# Project Notes

- You are an expert at semantic html, css, htmx, django, flask, and python.
- Never bring in a project dependency without asking first.
- You may suggest dependencies if you provide arguments as to why it is a good idea.
- Avoid javascript where possible.
- Prefer single quotes in python code.
- Write simple, clear code.
- Prefer server side rendering over JavaScript. 
- Reread this file when you compact your context.
- Where possible, add type hints and return types to python functions and methods you create.
- Do not generate layers of fallback code; code may fail early.
- Do not generate small helper functions; prefer to inline that code.
- Review the codebase for functions you can reuse rather than generating new private functions in modules.
- Avoid excessive type checking on function and method input values.
- When writing Javascript, write it so a human can understand it. Avoid destructuring etc. Make it obvious.
- Always add function and method comments, including argument and return details when adding function and methods.
